# Held-out benchmark: label audit (hands_on_llm_heldout_v1)

Every answerable item below was written by reading the book text (an independent `pdftotext` extraction of `hands_on_llm.pdf`) and labelled from that text.
No retrieval result of any kind (Dense, Hybrid, BM25, any earlier run) was consulted to write a question or to choose a page. Rules and method: `eval/HELDOUT_PROTOCOL.md`.

Columns: **pages** = physical PDF pages labelled relevant (strict labels); **chapter**; **evidence** = a verbatim excerpt with the page it was found on; the validator `scripts/validate_benchmark.py` re-found every quote in the *stored* chunk text of exactly these pages. Every full quote was also searched in the whole PDF text; the audit-remarks column would print `QUOTE ALSO ON [...]` if a quote occurred on an unlabelled page. It does not for any item.

## What the remarks mean

* **index pages (p571-596 etc.)**: the back-of-book index lists many terms; those pages are not passages that state an answer and are never labelled (the existing `--exclude-non-content` switch removes them from retrieval; the benchmark does not depend on it).
* **Also states part of the answer** (items m09, m10, a06): a second page restates one sub-fact. Strict labels (the primary result) do not count it; the *lenient* sensitivity labels (`hands_on_llm_heldout_v1_lenient.jsonl`) add exactly those three pages and nothing else. Both files were frozen before any held-out retrieval was run.
* **cross-reference only** (h01 p252: ‘as we saw before with the recency and primacy effects’; h10 p535: bibliography entry for ORPO): a page that mentions the term without stating the answer; not labelled.
